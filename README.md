## 功能概览

支持蓝牙与红外两种遥控方式：蓝牙通过 Android 公共 `BluetoothHidDevice` API 模拟键盘与媒体控制设备；红外通过手机内置发射器控制电视。19 个按钮按原装遥控器照片排列：顶部为 **静音、电源、信号源同一行**，其下为红绿蓝、方向盘、返回/音量+/主页、菜单/音量−/设置、bilibili/芒果 TV。

普通按键不依赖网络、ADB 或 Root；电视无需安装配套应用。蓝牙与红外均支持完整 19 个按键；按用户要求移除不支持的语音按钮及底部 TCL 字样。

两个应用快捷键使用用户提供的 SVG 图标，保留原始形状，统一使用深色按钮背景与浅灰色图标。源文件保存在 `docs/assets/`，Android 使用对应的 VectorDrawable；按钮保留中文无障碍名称。

应用名称为“TCL遥控器”，页面标题显示当前适配电视型号“TCL 55Q9K”。

应用图标使用用户提供的蓝色背景、白色遥控器与发光信号图，裁去四周透明留白，保留 PNG 透明通道，不添加额外底色。应用资源为 `app/src/main/res/drawable-nodpi/ic_launcher_art.png`，完整原图备份在 `docs/assets/launcher-blue-original.png`。桌面的最终形状由手机主题控制。

## 连接状态灯

标题左侧仅显示状态灯，不显示连接状态文字：蓝牙模式下绿色为已连接、黄色为 HID 已就绪但未连接、灰色为未就绪。红外模式下黄色表示手机红外已就绪，不能据此判断电视是否收到指令；右上角入口显示“红外设置”。长按灯可查看系统返回的具体原因，屏幕阅读器也能读取详情。连接、断开及配对操作位于右上角“连接设置”。

## 连接设置

右上角打开底部弹层，点击关闭按钮、空白遮罩或系统返回键即可关闭，不再挤占遥控按键区域。

- 顶部可切换 **蓝牙 / 红外**，默认使用蓝牙并记住上次选择。
- 蓝牙模式的设备选择与主按钮放在上方；主按钮根据权限、蓝牙和连接状态显示下一步操作，连接中禁止重复点击。
- **后台保持连接**独立一行，右侧信息按钮按需打开功能说明。
- **配对新电视**打开配对步骤与手机名称，不在遥控页面常驻提示。
- **更多**包含重试连接、重新配对上次电视、手机蓝牙设置和连接帮助。
- 操作结果使用短暂提示；需阅读的配对步骤、通知授权和故障处理使用弹窗。状态详情仍可长按指示灯查看。

## 红外使用步骤

1. 手机需内置红外发射器；应用会检测硬件和 38 kHz 载波支持。不支持的手机仍可使用蓝牙。
2. 打开右上角 **连接设置 → 红外**。切换后停止蓝牙连接和常驻服务，不要求附近设备或通知授权，也无需配对。
3. 将手机实际红外发射口朝向电视，保持无遮挡。当前小米 17 Pro Max 实测需将手机背面相机区域朝向电视，不能统一按“手机顶部”判断。
4. 使用电源、静音、信号源、方向、确定、返回、主页、菜单、音量和设置，共 14 个基础按键。方向、音量支持按住连发，松手或切后台立即停止后续发送。
5. **电源已在 TCL 55Q9K 上验证待机和再次开机**。电视须保持通电，发射口须对准电视；不要连续点击，以免唤醒后再次进入待机。
6. **红绿蓝快捷键、哔哩哔哩和芒果 TV 均已支持红外**，可以直接点击，无需切换蓝牙。红绿蓝执行电视上配置的原厂快捷功能；应用首次启动的协议或登录仍需自行完成。日常使用无需取消原装遥控器配对。
7. 红外不保活、不在后台发射；切回蓝牙会保留原来的自动连接和后台保持设置。手动断开过蓝牙时仍需手动重新连接。

红外说明通过设置中的 **红外使用说明** 按需查看。设备可能因为方向、距离或遮挡收不到信号，发射 API 返回成功不等于电视已执行。当前只验证了这台 TCL 55Q9K，其他型号需验证码表。协议与来源见 [IR_PROTOCOL.md](docs/IR_PROTOCOL.md)。

## 快捷设置磁贴

1. 打开右上角 **连接设置 / 红外设置 → 添加快捷磁贴**，在系统弹窗中点击添加。
2. 若系统不支持直接添加，下拉展开快捷设置（控制中心），进入编辑或“＋”，找到 **TCL遥控器** 并添加、调整位置。
3. 点击磁贴会收起面板并打开遥控器，保留上次选择的蓝牙或红外模式；锁屏时先完成解锁。

磁贴是打开应用的入口，不表示电视连接状态，也不会在后台发射红外或单独保持蓝牙连接。Android 13 及以上提供系统添加请求，旧版本显示手动添加指引。

## 完整蓝牙使用步骤

### 电视端准备

1. 用原装遥控器或电视实体按键打开电视，保持电视蓝牙开启。
2. 首次使用时进入电视的 **设置 → 蓝牙**，允许发现并搜索设备。
3. 配对成功后可以退出设置，停留在桌面或任意应用；日常不用重复搜索手机。

电视不需要安装 APK，不需要接电脑，不需要开启开发者模式或 ADB。电视 IP 只用于开发调试，日常遥控不使用 IP，也不要求手机与电视连接同一 Wi-Fi。保留原装遥控器，用于首次配对或红外无法对准时开机；蓝牙单独不能唤醒本机。

### 安装与首次配对

1. 在手机安装 `app/build/outputs/apk/debug/app-debug.apk`，打开“TCL遥控器”。
2. 打开右上角 **连接设置**，主按钮会根据当前状态显示 **允许附近设备**、**开启蓝牙** 或 **重试连接**；完成授权并等待状态灯变黄。
3. 点击 **配对新电视**，查看配对步骤，再点击 **让电视发现手机**，在系统弹窗中允许手机被发现。
4. 在电视蓝牙页面搜索并选择手机。当前手机名为 `BugMi17pm`，以配对说明弹窗中的手机名称为准。
5. 核对两端配对码并及时确认。仅建立蓝牙配对，无需授予通讯录或通话记录访问。
6. 回到手机“TCL遥控器”，在设备列表选择 `TCL 55Q9K-327F · E0:11`，点击 **连接电视**。列表也会显示其他已配对设备，请选择电视。
7. 状态灯变绿，设置弹层自动关闭，按钮亮起。先测试方向、确定和返回，然后正常使用。

### 从 0.1.x 升级到 0.2.0

新版扩展了 HID 键表。电视可能缓存旧描述符，出现方向键有效、彩色键和应用键无效的情况。需要刷新一次配对：

1. 手机蓝牙设置中取消与 TCL 电视的配对。
2. 电视蓝牙设置中取消与 `BugMi17pm` 的配对；**不要删除原装遥控器 `BT_RC802A_C1`**。
3. 手机回到TCL遥控器，等待 HID 注册，打开连接设置，点击 **更多 → 重新配对上次电视**。此按钮使用此前保存的电视地址；没有历史地址时按首次配对流程操作。
4. 保持电视开启蓝牙、允许被发现，核对两端新配对码并及时确认，再连接电视。

本次调试已为当前手机与电视完成上述重配对，正常使用无需再次操作。

### 日常使用与断开

1. 打开电视，两端蓝牙保持开启。
2. 手机打开TCL遥控器。HID 注册完成后会自动尝试连接上次保存且仍已配对的电视，状态灯从黄色变绿。若未成功，打开 **连接设置**，确认已选择电视后点击 **连接电视**。
3. 状态灯变绿后操作。应用会记住所选电视；仅页面可见且已连接时保持手机屏幕常亮。
4. 主动断开蓝牙时打开连接设置，点击 **断开连接**，或在后台连接通知中点击 **断开**。这会关闭后台保持、停止前台服务并暂停自动连接；再次手动连接后恢复自动连接。
5. 默认关闭后台保持：切后台或锁屏后释放按键并结束连接，返回前台后自动尝试重连。开启后台保持后：切后台仍释放所有按键，但保留蓝牙连接，返回页面可直接操作。电视关闭或不在范围内时不会持续重试；可手动重试或下次返回前台再试。

### 后台保持连接

此功能**默认关闭**。需要切换其他应用或锁屏时继续连接，可按以下步骤开启：

1. 连接电视后打开右上角 **连接设置**。
2. 打开 **后台保持连接**。Android 13 及以上首次使用时允许通知权限；拒绝通知不会影响普通前台遥控，后台保持不会开启。
3. 通知栏出现“已连接 · TCL 55Q9K”，现在可以切到其他应用或锁屏。返回遥控页面无需重新连接。
4. 只想恢复普通模式：关闭 **后台保持连接**，当前前台连接保留，下一次切后台才断开。
5. 结束使用：点击通知栏 **断开**，或应用内 **断开连接**；后台服务和通知随即结束，开关关闭，自动连接暂停。

开启期间会保留应用进程和蓝牙链路，使用系统 `connectedDevice` 前台服务与低重要度常驻通知。没有循环扫描、定时心跳、后台重连循环、CPU 唤醒锁或后台屏幕常亮；通知仅随状态变化更新。电视掉线时通知会显示状态，应用不持续重试。

本机一次后台样本的整个应用进程 PSS 约 58 MB，包含界面缓存，**不是后台功能的增量内存**。尚未进行拔电后的长期对照测试，不能据此给出每小时耗电百分比。系统强行停止应用、重启、蓝牙关闭或厂商省电清理仍可能断开；没有开机自启或自动复活机制。需要时重新打开应用连接。

## 按键功能

| 按钮 | 行为及限制 |
| --- | --- |
| 上、下、左、右、确定 | 移动焦点和确认；长按重复行为取决于电视及当前应用 |
| 返回、主页、菜单 | 返回上一页、回到桌面、打开当前页面支持的菜单 |
| 音量＋、音量−、静音 | 调整音量、切换静音 |
| 电源 | 发送待机/电源键；未连接时先尝试连接，连接成功后再按一次。蓝牙单独无法唤醒本机；可切换红外对准电视开机，或使用原装遥控器 |
| 信号源 | 打开电视信号源菜单 |
| 红、绿、蓝 | 使用电视已有的原厂自定义快捷配置；本机当前分别为 HDMI 1、斗鱼、酷喵，不会修改配置 |
| 设置 | 打开 TCL 快捷设置面板 |
| bilibili、芒果 TV | 打开电视已安装的对应应用；首次使用的隐私协议、登录等由用户自行处理 |

按钮支持无障碍点击。松手、移出按钮、取消触摸、页面暂停时释放按键。红外模式使用手机内置发射器，全部 19 键已在本机验证；应用快捷键及 TCL 扩展键可能因其他电视固件而不同。

## 功能范围

当前不提供语音功能。电视原生语音助手未能通过本应用的经典蓝牙 HID 呼出，已按用户要求移除语音按钮，不使用手机识别或文字搜索代替。底部 TCL 品牌文字也已移除。语音请使用原装遥控器。

已专门验证“只呼出助手”：原装遥控器未配对时，语音键红外码 `0xFA3` 只触发配对提示；恢复配对后原装语音键可正常呼出助手。该红外码不能作为助手按钮，当前仍未找到本应用可用的独立触发方式。

## 故障排查

1. 未注册：确认附近设备权限、蓝牙开关；打开连接设置，点击 **更多 → 重试连接**，关闭其他 HID 键鼠模拟应用。
2. 未连接：确认电视开机且在蓝牙范围内，列表选中正确电视，再连接。电视无需停留在蓝牙页。
3. 仅新增键无响应：按“从 0.1.x 升级”取消双方旧配对并重新配对。
4. 配对超时：重新发起，两端配对码一致后及时确认；不要删除原装遥控器。
5. 电视待机后蓝牙无法连接：切换红外并对准电视按一次电源，或用原装遥控器/实体按键开机，再连接蓝牙。
6. 安装提示 `INSTALL_FAILED_USER_RESTRICTED`：检查手机正常安装确认及“USB 安装”设置，不关闭系统安全检查绕过限制。

仅保存所选电视地址、遥控模式、自动连接及后台保持选项，关闭应用数据备份。蓝牙后台模式额外使用通知权限和连接设备前台服务权限。红外使用普通权限 `TRANSMIT_IR`，不要求蓝牙连接。不申请 INTERNET、录音、定位或无障碍服务权限。

## HID 映射

| 功能 | Report ID | Usage |
| --- | --- | --- |
| 上 / 下 / 左 / 右 / 确定 | 1，8 字节 Keyboard | `0x52 / 0x51 / 0x50 / 0x4F / 0x28` |
| 电源 / 信号源 | 1 | `0x66 / 0x97` |
| 红 / 绿 / 蓝 | 1 | `0x99 / 0x9A / 0x9B` |
| 设置 / bilibili / 芒果 TV | 1 | `0xA8 / 0xD1 / 0xD3` |
| 返回 / 主页 / 菜单 | 2，2 字节小端 Consumer | `0x224 / 0x223 / 0x40` |
| 音量加 / 音量减 / 静音 | 2 | `0xE9 / 0xEA / 0xE2` |

Keyboard 描述符支持至 `0xFF`。TCL 扩展映射来自本机原装输入设备的只读键表查询及原装按键采集；查询源码见 `tools/read-hid-keymap.c`，使用 `EVIOCGKEYCODE_V2`，不写入或修改输入设备。原装语音 `Keyboard 0xAD` 被映射为 UNKNOWN，不能用普通 HID 按键代替其音频流程。
